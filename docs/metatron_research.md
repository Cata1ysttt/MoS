## 原文核心机制

1. **结构化部分目标，不是自然语言直接驱动关节。**III-B 的prompt含带到达时间的世界坐标身体位置/朝向、规范化姿态、平面速度、风格示例及场景包围盒。不同身体、属性、时刻通过mask选择；未约束的自由度由底层协调。规范化姿态相对于目标躯干/朝向，不是当前机器人偏移。风格帧池化后丢弃时间顺序，不能承担精确触球时序。
2. **先训练密集跟踪专家，再蒸馏部分目标控制器。**III-A/D 用PPO训练完整参考跟踪器；随机mask目标，混合专家和posterior引导学生轨迹，在访问状态上标注专家动作。不是只训练现有冻结模型上的小型prompt网络。
3. **条件VAE缓解部分目标的多解问题。**III-C/D：prior只看部署观测和prompt；训练posterior额外看完整参考与特权状态。动作重建、prior/posterior KL、条件预测、表征时间一致性和动作平滑联合训练；latent投影到单位球，与确定性条件融合后解码。这个随机latent不是AH-BFM的256维范数16行为接口。
4. **冻结后用有状态技能程序产生目标。**IV：人写初始规则，coding agent分析动作、拟合少量参数，在仿真playground中迭代。程序实时更新目标和阶段；LLM不在关节实时闭环内。走路示例用速度/行进角决定周期脚轨迹，坐下用躯干和双脚三个粗目标。
5. **能力依赖训练覆盖。**V包含重定向运动、场景交互和合成恢复；G1采用BONES、AMASS+LAFAN、recovery、SAMP四类专家。VII明确承认意外动作、外部目标供给和硬件量化不足；不是任意新接触任务无需训练的保证。

## 与当前方案的差别

当前系统：仿真任务观测 -> projector -> z -> 冻结AH-BFM -> 关节目标。训练主要是专家动作MSE，缺少匹配backward encoder，属于action-only LPP。新增辅助回放未改善方向成功率。

METATRON把对上层友好的几何、时间、mask接口训练进执行层。仅把我们的projector称作prompt生成器不会自动获得这种能力。其论文未在所读实验中证明准确足球传球；不能将坐下/恢复结果外推为动态撞击控制成功。

## 建议结合的形式化（以下是我们的研究提案）

令任务目标 g=(目标方向,目标速度)，状态估计 o 包含球与机器人；阶段 c 和程序参数 alpha：

c_(t+1)=T(c_t,o_t,g)

p_t=S_alpha(c_t,o_t,g)={(身体部位i,到达时间tau,位置目标,朝向目标,mask)}

z_t=A_phi(b_t,p_t,history)，a_t=pi_BFM(b_t,z_t)

其中A是需要训练/验证的prompt-to-latent适配器，现有actor没有原生p输入。优先指定支撑脚位置、踢球脚的触球前/触球/随挥目标和躯干朝向。脚速可由相邻时间目标间距近似约束；直接脚速/接触力接口属于扩展，不应归为论文原生设计。

足球技能程序：接近/预定位 -> 准备支撑 -> 挥脚触球 -> 随挥 -> 恢复。触球时刻根据球运动预测持续更新；阶段切换用接触反馈并设置超时恢复，不能只按固定倒计时。

## 最值得做的实验

1. 从现有专家轨迹提取稀疏脚/躯干目标和触球时刻，先测目标重建误差及可达性；几何目标相同不代表出球结果相同。
2. 同数据预算比较直接观测到z、带时间目标到z、去掉时间、去掉mask、去掉阶段状态。报告方向/力度联合成功率、稳定性、推理成本及未见来球泛化。
3. 学习适配器时保留原策略/动作约束，加入短时rollout接触结果监督。仅做当前状态正运动学无法得到动作对未来接触的梯度；需要仿真采样、可学习前向模型或任务RL。
4. 若存在多解，用条件prior/posterior学习“哪种动作完成方式”，引入参考或专家信息只供训练；评估必须只用prior。不直接回归可能不唯一的oracle z。
5. Agent改写可解释的阶段/几何规则，数值优化负责连续参数，仿真验证后接受修改。与固定规则、纯数值搜索比较，固定交互/计算预算。

## 论文定位

有潜力的主张：从姿态目标执行扩展到**接触事件可编程执行层**，把接触时刻、足部几何和期望出球结果连接起来。需要证明不只是手工状态机或更强监督带来的收益。尚未完成相关工作穷尽检索，不能宣称新颖或保证顶会。

当前不应立刻重训整个METATRON。先用已有专家与冻结AH-BFM验证“显式时间/接触目标是否改善泛化与可纠正性”；只有适配接口确实不可达时，再考虑重训执行层或底层适配。
