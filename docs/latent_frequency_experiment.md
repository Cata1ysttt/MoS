# 近球交互优化：冻结 AH-BFM 的 latent 更新频率对照

2026-11-08。目标是改善自主传球方向、漏球及提前终止，不以模仿 loss 代替任务结果。
现有录像证明部分 latent 可以产生有效传球，但不能证明底层覆盖所有足球动作。

## 本轮改动

- 原方式每5个物理控制步更新latent，即10Hz；新增每步更新，即50Hz。
- 训练采集、专家回放、执行和评估使用一致的窗口长度；checkpoint记录间隔。
- 老checkpoint缺少间隔字段时继续按5步部署。
- 两组均从 `lpp_expert_replay_v2/latest.pt` 继续训练64,000 transitions，64环境，seed810130。
- 每轮均采集50控制步、进行相同次数的优化；每次优化均回放320个专家目标，接触附近4倍采样。
- 两组都冻结AH-BFM与专家，仅训练projector。不是完整FIBER LPP：仍缺少官方backward encoder。
- 评估均使用seed810127、64回合、40秒上限；这是已使用的开发集，不能作为最终独立测试集。

初始v1试启动的专家回放窗口数相同、目标数不同，已停止并保留日志；不纳入结论。
正式结果使用 `frequency_50hz_64k_v2` 和 `frequency_10hz_64k_v2`。
训练/评估顺序及状态见 `scripts/run_frequency_ablation.py`、`runs/frequency_ablation_v2_status.json`。
未更改g1-rollingball原环境或停止其他训练。

## 如何判断

首先核对初始物理状态哈希、球运行参数与回合数量，再比较首球触球、原环境首球方向快照、
全部方向事件、提前终止及漏球。方向快照不等于统一碰撞后时间的精确球速测量。
相同预算仍不代表完全相同训练样本：策略产生的访问状态和连续回放窗口相关性会改变。
50Hz下每个专家状态可独立预测latent，10Hz下五步共享一个端点，这是本轮要验证的约束。

若50Hz改善，再做更长训练和未使用种子评估；若仍方向不准，下一轮优先加强近球/脚部监督，
或蒸馏已验证成功的专家辅助latent序列。任务reward优化尚未实现，不将其写成已有训练内容。

## 验证

10项现有及新增测试通过，包括单步回放对齐、跨reset历史处理、旧五步窗口及执行模式梯度。
最终效果以闭环结果为准，训练启动和有限loss都不代表已解决传球。

两组均完成64,000 transitions和64回合闭环评估；初始状态哈希及球运行参数一致，actor保持冻结。
